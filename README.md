### 🛠️ Primitive Modding Guide

**Author:** fishiatee

A comprehensive guide for modding Allumeria the "primitive" way — modifying assemblies directly using ILSpy and dnSpy [citation:3].

**What You Can Do**:
- Change game window title and version text
- Add custom items with custom textures
- Modify existing game mechanics
- Create entirely new content

**Requirements**:
- Basic C# knowledge
- ILSpy (for reading code)
- dnSpy (for modifying code)
- sfextract (for unpacking R2R exe)

**Quick Start**:
1. Unpack the R2R exe using `sfextract PocketBlocks.exe -o ..\modded`
2. Change `includedFrameworks` to `frameworks` in `.runtimeconfig.json`
3. Use ILSpy to read code and dnSpy to modify it
4. Save changes using "Save All" in dnSpy [citation:3]
